# C 라이브러리 학습 부록 색상 목차 및 재정렬 설계

## 목적

기존 2분 발표용 슬라이드 1~4는 변경하지 않는다. 학습 부록 앞에 색상 목차를 추가하고, 함수별 슬라이드를 같은 색상끼리 연속 배치해 초보자가 분류와 순서를 한눈에 이해할 수 있게 한다.

## 슬라이드 구성

- 슬라이드 1~4: 기존 발표 자료를 그대로 유지한다.
- 슬라이드 5: `학습 자료 목차`를 새로 추가한다.
- 슬라이드 6~21: 함수 16개를 네 분류별로 네 장씩 배치한다.

## 색상과 함수 순서

1. 민트 — 문자열 탐색·비교·분리
   - `strchr`, `strcmp`, `strlen`, `strtok`
2. 파랑 — 문자열·메모리 복사와 초기화
   - `strcpy`, `strncpy`, `memcpy`, `memset`
3. 코랄 — 동적 메모리와 수명 관리
   - `malloc`, `realloc`, `free`, `strdup`
4. 노랑 — 출력·오류·프로그램 종료
   - `printf`, `snprintf`, `perror`, `exit`

## 디자인

목차는 기존 덱의 남색 배경, Pretendard와 Consolas 글꼴, 민트·파랑·코랄·노랑 강조색을 그대로 사용한다. 각 분류는 색상 제목과 함수 이름 네 개로 표시한다. 함수별 슬라이드의 본문과 디자인은 변경하지 않고 순서와 슬라이드 번호만 조정한다.

## 검증 기준

- 전체 슬라이드는 21장이다.
- 슬라이드 1~4의 렌더링 결과는 기존 파일과 동일하다.
- 목차의 함수 순서와 슬라이드 6~21의 실제 순서가 일치한다.
- 함수 16개가 정확히 한 번씩 등장한다.
- 텍스트 잘림, 겹침, 폰트 정책 오류가 없다.
