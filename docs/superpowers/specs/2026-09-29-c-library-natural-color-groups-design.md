# C 라이브러리 함수 자연 분류와 색상 통일 설계

## 목적

함수 개수를 네 개씩 맞추기 위해 만든 인위적인 분류를 제거한다. 함수가 실제로 하는 일과 사용할 때 주의할 점을 기준으로 `4·5·4·3`개로 분류하고, 발표용 슬라이드와 학습용 부록에서 같은 함수가 같은 색으로 보이게 한다.

## 최종 분류

1. 민트 — 문자열 탐색·비교·분리
   - `strchr`, `strcmp`, `strlen`, `strtok`
2. 파랑 — 버퍼 복사·초기화·크기 제한 쓰기
   - `strcpy`, `strncpy`, `memcpy`, `memset`, `snprintf`
3. 코랄 — 동적 메모리와 수명 관리
   - `malloc`, `realloc`, `free`, `strdup`
4. 노랑 — 출력·오류 표시·프로그램 종료
   - `printf`, `perror`, `exit`

`snprintf`는 출력 형식을 사용하지만, 목적지 버퍼와 크기 `n`을 받아 범위 안에 쓰는 함수다. 이번 자료의 메모리 안전성 관점에서는 파란색 그룹에 둔다.

## 슬라이드별 변경

### 슬라이드 1

오른쪽 대표 함수를 다음과 같이 교체한다.

- 민트: `strchr()`
- 파랑: `strcpy()`
- 코랄: `malloc()`

기존의 노란색 `free()`는 제거한다. 세 함수는 각각 주소, 범위, 수명을 소개하는 슬라이드 2~4와 연결된다.

### 슬라이드 2~4

함수 이름에 사용하는 색상을 최종 분류와 일치시킨다.

- 슬라이드 2: `strchr`, `strcmp`, `strtok`은 민트, `malloc`, `realloc`은 코랄
- 슬라이드 3: `strlen`은 민트, `strcpy`, `strncpy`, `memcpy`, `memset`, `snprintf`는 파랑
- 슬라이드 4: `malloc`, `realloc`, `free`는 코랄, `strchr`, `strtok`은 민트

### 슬라이드 5

함수 개수를 표시하는 `1번째 묶음 · 4개 함수` 형식의 보조 문구를 모두 삭제한다. 분류 이름과 함수 목록만 남긴다.

하단 설명은 다음 문장으로 변경한다.

> 색이 같은 함수끼리는 하는 일과 사용할 때 조심할 점이 비슷합니다.

목차의 함수 목록은 최종 분류와 동일하게 표시한다.

### 슬라이드 6~21

목차 순서에 맞춰 다음 순서로 배치한다.

```text
strchr, strcmp, strlen, strtok,
strcpy, strncpy, memcpy, memset, snprintf,
malloc, realloc, free, strdup,
printf, perror, exit
```

`snprintf`의 강조색은 파랑으로 변경한다. 페이지 번호와 `REFERENCE NN / 16` 번호는 새 순서를 반영한다.

## 검증 기준

- 전체 슬라이드는 21장이다.
- 16개 함수가 정확히 한 번씩 함수별 슬라이드에 등장한다.
- 목차와 슬라이드 6~21의 순서 및 색상이 일치한다.
- 슬라이드 1의 세 대표 함수 색상이 민트·파랑·코랄과 일치한다.
- 슬라이드 2~4의 함수 이름 색상이 최종 분류와 일치한다.
- 텍스트 잘림, 겹침, 폰트 정책 오류가 없다.
