# C 라이브러리 함수 2분 발표 디자인

## 목적

C 초보자와 경험자가 섞인 교육생을 대상으로, 디버깅 과제에 등장한 C 라이브러리 함수를 메모리 안전 관점에서 2분 안에 설명한다.

## 범위

- 총 4장, 발표 목표 시간 1분 45초에서 1분 50초
- `printf`, `perror` 등 일반 출력·진단 함수의 상세 설명은 제외
- 슬라이드에는 함수 이름의 유래와 한 줄 기능을 남기되, 발표자는 대표 함수만 설명
- 핵심 질문은 주소의 유효성, 접근 범위, 메모리 수명으로 제한

## 슬라이드 구성

### 1. C 라이브러리 함수와 메모리 안전

- 약 15초
- `strchr`, `malloc` 등은 C 문법의 내장 함수가 아니라 표준 라이브러리 함수
- 핵심 문장: 라이브러리는 기능을 제공하고, 호출자는 사용 조건을 확인한다

### 2. 반환된 주소의 유효성

- 약 30초
- 대표 함수: `strchr`
- 짧은 코드로 성공 시 위치 포인터, 실패 시 `NULL`을 시각화
- 보조 함수: `malloc`, `realloc`, `strtok`, `strcmp`
- 함수명 풀이와 한 줄 기능을 작은 참고 정보로 제공

### 3. 메모리 접근 범위

- 약 30초
- 대표 함수: `strcpy`
- `"hello"`가 널 문자를 포함해 6바이트라는 점을 시각화
- 보조 함수: `strlen`, `strncpy`, `memcpy`, `memset`, `snprintf`
- 각 함수가 실제 버퍼 크기를 자동으로 아는지 정확히 구분

### 4. 메모리 수명

- 약 35초
- 대표 함수: `malloc`, `realloc`, `free`
- 할당부터 해제까지의 유효 구간을 타임라인으로 표현
- `strchr`, `strtok`의 반환값은 원본 내부 주소라는 점을 짧게 표시
- 결론: 주소, 범위, 수명을 확인한다

## 시각 디자인

- 16:9 와이드 화면
- 짙은 네이비 배경, 밝은 아이보리 본문, 민트와 코랄 포인트 색상
- 큰 제목과 모노스페이스 코드 중심의 단일 구성
- 카드 그리드와 긴 표를 피하고, 슬라이드마다 한 개의 큰 시각적 설명 사용
- 함수명은 크게, 영문 이름 풀이와 한국어 기능은 작게 배치
- 본문 최소 20pt, 제목 32pt 이상

## 발표자 노트

- 슬라이드별 말할 내용을 15초, 30초, 30초, 35초 분량으로 작성
- 화면의 모든 함수명을 읽지 않음
- 대표 함수의 동작과 실패 조건만 말하고 나머지는 참고용으로 둠
- 전체 대본은 자연스러운 한국어 구어체로 작성

## 검증 기준

- 4장 전체가 2분 안에 발표 가능
- `strchr`와 버퍼 크기에 관한 설명을 혼동하지 않음
- `strncpy`의 널 종료 문제와 `snprintf`의 잘림 가능성을 정확히 표현
- `realloc` 성공 시 기존 주소가 무효가 될 수 있음을 정확히 표현
- 모든 텍스트가 잘리지 않고 16:9 화면에서 읽힘
